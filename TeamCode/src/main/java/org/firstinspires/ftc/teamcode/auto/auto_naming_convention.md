# Auto Naming Convention 

#### Read if confused on which auto is which: 

* Autos are named in the format: [alliance, side, type, no. of tips]
* Alliance = red/blue
* Side = which side of the field, i.e: above the half line of y = 70.75 is UP, and below is DOWN
* Type = Solo/With alliance 
* No of tips = 1,2,3... etc
* Paths are named the same as their corresponding auto but with the word 'Path' at the end, and are in a different package
* OPTIONAL - version at the end of name, eg: V2, V3... etc
eg: RedUpSolo3 = Red alliance solo auto starting on the upper half of the field (y) with 3 tips
